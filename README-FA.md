# میز کار زرگر — راهنمای قرار دادن روی اینترنت

## ۱. آپلود روی هاست رایگان
**Netlify (ساده‌ترین):**
1. فایل زیپ را باز کنید تا یک پوشه بسازد.
2. به app.netlify.com/drop بروید و **کل پوشه** را بکشید و رها کنید.
3. Netlify یک لینک https می‌دهد. همان لینک برنامهٔ شماست.

**Cloudflare Pages:** در بخش Workers & Pages گزینهٔ Create → Pages → Upload assets را بزنید و فایل‌ها را آپلود کنید.

اگر خواستید دامنهٔ خودتان را (مثلاً zargar.ir) در تنظیمات هاست وصل کنید.

## ۲. نصب مثل برنامه
- **آیفون:** لینک را در Safari باز کنید ← Share ← Add to Home Screen.
- **اندروید:** در Chrome منوی ⋮ ← Install app (یا Add to Home screen).

آیکون لوگوی شما و نام «میز زرگر» روی صفحه می‌نشیند و برنامه بدون نوار آدرس باز می‌شود.

## ۳. کار بدون اینترنت
بعد از اولین باز کردن، همهٔ ماشین‌حساب‌ها بدون اینترنت کار می‌کنند. فقط فونت فارسی بدون اینترنت جایش را به فونت پیش‌فرض گوشی می‌دهد.

## ۴. بعد از هر تغییر
فایل `index.html` را عوض کنید، در `sw.js` عدد نسخه را بالا ببرید (`gb-v1` ← `gb-v2`) و دوباره پوشه را آپلود کنید. در غیر این صورت کاربرها نسخهٔ قدیمی را می‌بینند.

## ۵. نکته‌ها
- قیمت زندهٔ طلا در این نسخه نیست و به سرور جداگانه نیاز دارد. عدد را کاربر دستی وارد می‌کند.
- لیست طلاهای آب‌شده روی دستگاه هر کاربر ذخیره می‌شود و به دستگاه دیگر نمی‌رود.
- محاسبه‌های سنگ، ریخته‌گری، سیم و رنگ تقریبی‌اند و برای کارهای مهم باید با ترازو چک شوند.
